# 아이펠 에이전트 과제2 - 게임 만들기

# 개요
각종 무기를 사용하여 건물을 파괴하세요

# 목표
제한된 무기로 최대한 건물을 파괴하고 점수를 획득하세요.

## 게임 실행

👉 **[건물 부수기 게임 플레이하기](https://jsseo0420.github.io/ai-agent-work2/)**



# 회고
1. 추가 요청을 통해 화면을 3D, 위성 느낌으로 표현하는것까지는 적용.
2. 건물의 옆면, 앞면을 표현하고 싶으나 건물에 대한 데이터가 부족하여 표현할 수 없다고 함. 
3. 특정 무기는 사용자가 눈앞에서 날라가는것처럼 요청하여 수정함.
4. 특정 무기는 날라갈때 원근감을 주기 위해 무기의 크기가 건물에 가까워질수록 점점 작아지게 만들어달라고 요청하여 수정함.
